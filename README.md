# GeofencedDashboard

A CSV-only analytics dashboard for the Geofenced Attendance app.

Professors can upload exported attendance CSV files to view class summaries, attendance distribution, student status, target-based charts, and recovery plans. All data is processed locally in the browser; no database or server is required.

## Run

Open `index.html` in a browser, then upload a CSV with these columns:

`RollNo, Name, Branch, Section, Subject, TotalClasses, PresentClasses`
